# 🎬 Netflix Power BI Dashboard

## 📌 Project Overview

This interactive **Netflix Power BI Dashboard** analyzes Netflix's content library to uncover meaningful insights into movies, TV shows, genres, ratings, countries, and release trends. The dashboard transforms raw data into clear visual stories, helping users explore Netflix's global content catalog through dynamic and interactive reports.

---

## 🚀 Tools & Technologies

* 📊 Power BI
* 🔄 Power Query
* 🧮 DAX (Data Analysis Expressions)
* 📑 Microsoft Excel

---

## ✨ Dashboard Highlights

* 📈 Interactive KPI Cards
* 🎬 Movies vs TV Shows Distribution
* 🌍 Country-wise Content Analysis
* 🎭 Genre Distribution & Popular Categories
* 🔞 Content Rating Analysis
* 📅 Year-wise Release Trends
* 🎛 Interactive Slicers & Filters
* 📖 Data Storytelling with Visual Insights

---

## 📊 Key Insights

* Compare the proportion of **Movies** and **TV Shows** available on Netflix.
* Discover which **countries contribute the most content**.
* Analyze the **most popular genres** on the platform.
* Explore how Netflix's content library has grown over the years.
* Understand the distribution of **content ratings** across titles.
