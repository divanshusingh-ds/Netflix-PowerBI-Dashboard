# Netflix Power BI Dashboard

## Project Overview
This dashboard provides insights into Netflix content, including movies, TV shows, genres, ratings, countries, and release trends.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Key Features
- KPI Cards
- Movies vs TV Shows Analysis
- Genre Analysis
- Country-wise Content Analysis
- Interactive Filters
- Data Storytelling
