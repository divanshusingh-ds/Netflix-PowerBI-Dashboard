# 🎬 Netflix Power BI Dashboard

## 📌 Project Overview

The **Netflix Power BI Dashboard** is an interactive Business Intelligence project designed to transform raw Netflix content data into meaningful insights through dynamic visualizations. This dashboard provides a comprehensive overview of Netflix's global content library, enabling users to analyze trends in movies, TV shows, genres, ratings, countries, and release patterns. Built with Power BI, it demonstrates modern data visualization techniques and supports data-driven storytelling for better decision-making.

---

## 🚀 Tools & Technologies

* 📊 Microsoft Power BI
* 🔄 Power Query
* 🧮 DAX (Data Analysis Expressions)
* 📑 Microsoft Excel

---

## ✨ Dashboard Highlights

* 📈 Executive KPI Cards
* 🎬 Movies vs TV Shows Analysis
* 🌍 Country-wise Content Distribution
* 🎭 Genre & Category Analysis
* 🔞 Content Rating Breakdown
* 📅 Year-wise Release Trends
* 🎛 Interactive Slicers & Filters
* 📖 Data Storytelling through Visual Analytics

---

## 📊 Key Insights

* Compare the distribution of **Movies** and **TV Shows** available on Netflix.
* Identify the **top countries** contributing the largest amount of content.
* Explore the **most popular genres** and content categories.
* Analyze the growth of Netflix's content library over time.
* Understand the distribution of **content ratings** across different titles.
* Gain quick business insights through interactive KPIs and visual reports.
